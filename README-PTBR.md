### ZombieGame
Um jogo 2D feito em OpenGL onde você enfrenta hordas de zumbis.

Ao executar o .\ZombieShooter.exe, o usuário é recebido por uma tela inicial contendo os comandos para jogar. Para começar a jogar, basta pressionar 'enter'.

<img width="798" height="621" alt="image" src="https://github.com/user-attachments/assets/300d3f3a-bbbf-49a9-83d9-98ee19565d0a" />

O jogador possui 3 vidas. Para cada inimigo que cruzar a linha, ele perde 1 vida. As vidas são representadas pelas 3 barras vermelhas no canto superior direito.
A pontuação no canto superior direito representa o número de inimigos mortos, e o contador é reiniciado a cada novo jogo.

<img width="798" height="631" alt="image" src="https://github.com/user-attachments/assets/2013b69c-8c83-49d8-bd1b-561827058c30" />

O jogador pode atirar nos inimigos a uma taxa limitada de no máximo 2 tiros por segundo. Cada tiro que acerta um inimigo remove 1/3 da sua barra de vida. Após 3 tiros, a vida do inimigo chega a zero e ele desaparece.

<img width="798" height="631" alt="image" src="https://github.com/user-attachments/assets/0b517885-e496-465c-a154-2874b471976c" />





Após 3 inimigos cruzarem a linha branca, o número de vidas do jogador chega a 0 e o jogo termina.
